description: 使用者要求 /session-close、結束本次工作階段並收尾記憶時，只寫本地結束記號，由 CC-memory 背景採集完成後重寫整場摘要。
---

執行專案的 `hooks/session-close.sh`。Claude Code 與 Codex 共用此腳本。

1. 從本次執行環境或本次掛鉤紀錄取得目前 `session_id`、`transcript_path` 與 `cwd`。不得猜測 ID、挑最近的其他對話或使用其他工作階段的路徑。若環境沒有提供，請使用者提供這些值；沒有逐字紀錄的暫時工作階段無法採集。
2. 將三個欄位序列化為 JSON（資料交換格式），透過標準輸入交給腳本。以參數陣列啟動 `bash`，不要把使用者提供的路徑直接插入命令文字。腳本位置以本技能來源的 CC-memory 儲存庫根目錄為準，不是待收尾專案的 `cwd`；安裝到全域時先確認 CC-memory 實際位置。
3. 腳本只追加抽取邊界及寫入結束記號；不連資料庫、不呼叫模型、不啟動服務。沿用既有 Stop（回合結束）掛鉤喚醒採集。
4. 檢查對應 `.jsonl.close` 與 `.jsonl.finalize.json` 是否存在，再回報「已排入收尾，背景抽取追上後執行」。腳本為 best-effort（盡力執行），結束碼 0 不代表已寫成功；記號未產生時回報未排入，不宣稱摘要已完成。

`__personal__` 與採集子程序不得建立記號。不要直接改資料庫、替使用者總結整場對話，或修改全域工具設定。
